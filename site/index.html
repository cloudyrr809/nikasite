Книга класса

30–40 полных разворотов

Что внутри

  • совместно разработанная обложка
  • разворот портретов каждого ученика
  • разворот с крупным портретом классного руководителя и учителей
  • большой блок с индивидуальными страницами каждого ученика с выбранными им фотографиями, индивидуальной проработкой дизайна и цитатами
  • несколько разворотов с групповыми снимками
  • 2 разворота с масштабными общими фотографиями, отражающими вайб класса

Особенности формата

  • возможность каждого ученика стать полноценным соавтором своего альбома
  • свобода самовыражения каждого на персональных страницах
  • много разворотов для максимального количества фотографий, которые создают целую историю
  • журнальный стиль страниц из плотной мелованной бумаги, с сохранением твёрдой обложки

Классический альбом

7–8 полных разворотов

Что внутри

  • личная фотография
  • разворот с портретами всех одноклассников
  • разворот с классным руководителем и учителями
  • несколько групповых снимков
  • общая фотография всего класса

Особенности формата

  • плотные страницы на пластиковой основе, которые не гнутся и сохраняют свой вид на долгие годы
  • только самые важные фотографии
  • строгая эстетика без детальной персонализации для каждого ученика
